Правила командной работы
Основная ветка: main.
Именование веток: feature/название-задачи.
Сообщения коммитов должны быть осмысленными (например, "Добавлена логика стрельбы").
Так как проект выполняется одним участником, проверка изменений осуществляется через git diff перед коммитом.
Правило актуальности: содержание отчетов меняется в Markdown, после чего обновляется Word-версия перед сдачей.

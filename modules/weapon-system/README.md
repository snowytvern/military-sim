# Модуль системы стрельбы (Weapon System)

## Разработчик
Шахворостов Никита Аркадьевич

## Назначение
Модуль отвечает за обработку стрельбы, контроль времени перезарядки орудия и расчет урона по цели.

## Связанные требования
ФТ-06 Стрельба из орудий

## Связанный вариант использования
UC-07 Стрельба и разрушение объектов

## Входные данные
Текущее время в секундах, факт попадания в цель (логическое значение).

## Результат
Строка с отчетом о действии: перезарядка, промах или нанесенный урон.

## Запуск
Для проверки логики модуль можно запустить как консольное приложение через метод Main в классе Program. В Unity используется путем вызова метода TryShoot из скрипта вооружения.

## Текущее состояние
Реализована базовая логика перезарядки и расчета урона.
